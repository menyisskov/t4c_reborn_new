# Shattered Isle (T4C-0155)

The approved island sits in formerly empty ocean east of Drake's Lair. The
island is installed in the world map and collision data. The staging builder
and preview record the reviewed design; the preview uses colors sampled from
the game's native rock, earth, grass and water tiles.

| Place | World tile |
|---|---|
| Central landing | (3450, 2705) |
| Obsidian Dragon, volcanic ridge | (3360, 2635) |
| Bronze Griffin, dry upland | (3540, 2635) |
| Swamp Hydra, marsh | (3450, 2790) |

The collision map has one 83,718-tile land component, separate from
the mainland. All four locations have fully walkable 9×9 neighborhoods.
The builder rejects occupied terrain before painting.

Access quest: Outrider Kaelis at Drake's Lair asks the player to
defeat three Kraanian Dragonguards on the approach. Turning in the quest
permanently opens Shattered Isle and Drake's Lair return travel in the
Locations panel. The player arrives in the central clearing, away from all
three bosses. No level requirement or rare item is needed.
